# Windows annual eligibility release verification

This report accompanies `run_windows_annual_eligibility_regression.py` and the
approved v14 correction that reapplies the current landscape domain after
loading cached, NPA-adjusted sourcing weights. The release also adds a true
fixed-input branch for LUC = 1. The v13 scientific model is retained unchanged.

## Test design

- Windows Dinamica EGO 2.4.1, native expressions enabled, one processor,
  predefined engine seed, isolated temporary directories, serial execution.
- A frozen real-data fixture of 269 × 273 cells (73,437 cells), three years
  (2000–2002), and three distinct frozen draws for initial stock, carrying
  capacity and growth rate.
- Capped and uncapped fixed-cover pairs compare retained v13 against corrected
  v14. All year-labelled input rasters are absent in both fixed fixtures; this
  verifies that the new fixed-input branch does not require annual map copies.
- Capped and uncapped changing-cover pairs compare corrected v14 against an
  independent annual-recomputation reference: the original v14 cold cache
  branch, containing its original NPA and landscape-mask arithmetic, is forced
  to execute every year. This reference never reuses a cached masked weight.
- One changing-cover capped pair additionally enables the stochastic Patcher.
- Dynamic fixtures select LUC channel 3. Controlled MODIS-compatible class
  rasters and both category tables are copied to channel 3 names in temporary
  fixtures, so input-channel selection changes without changing class meaning.
- Four external R preparation/report calls are removed identically. Monte
  Carlo draws are copied and hash checked, never regenerated by these tests.
- Per-origin W/V pressure and W TOF redistribution maps are added as observers;
  none feeds back into the model. The sourcing reader separately replays these
  maps and the aggregate pressure from the candidate's capture contract.

## Acceptance conditions

Input hashes must match within each pair. All comparable output CSV files,
including the binary64 scalar codec, must match byte for byte. Raster values,
NoData masks, geometry and datatype must match exactly.

For the v13/v14 fixed-cover comparisons only, the previously approved initial
model-stock support rule permits explicitly enumerated auxiliary differences
at cells whose initial model stock is missing. Changes at initially eligible
cells are forbidden. Realized harvest, growth, stocks, per-origin pressure
observers and every CSV have no tolerance or exception.

The legacy static sourcing-capture files are not compared with the new capture
contract: the reference caches a masked map, whereas the candidate records an
unmasked NPA map plus annual eligibility and annual accumulator domains.
Independent reader replay validates the new captures against direct runtime
observers. This exclusion does not exclude the sourcing scalar files or
per-origin pressure observers from the model comparison.

Two persistent TOF-to-forest cohorts supplement the original zero/NoData,
forest loss/return and domain reentry cases. They convert in 2001, remain
forest in 2002, and therefore exercise eligibility after the conversion year
while the candidate is using a warm cache. Their diagnostic report records
available biomass, the vehicle mask, vehicle pressure and total realized
harvest. In both three-year growth modes, the post-conversion
stock remains below the vehicle threshold, so these cohorts do **not** yet
demonstrate positive restored harvesting pressure. The earlier 20 native
eight-cell probes cover positive eligibility and normalized pressure at annual
steps 1, 2, 3, 11 and 12 against annual recomputation; the full-graph test adds
integration and frozen-MC coverage rather than extending that positive-pressure
claim to this short simulation.

## Evidence

Temporary diagnostics are under
`E:/MoFuSS_Active/mdg_v14_annual_eligibility_release_2026-10-06/integration`.
`integration_release_gate.json` binds each result to the uninstrumented source
model SHA-256 and requires all five comparison pairs. Reader replay has its
own release gate. These temporary outputs may be deleted once conclusions and
the source tests have been preserved.

This is a bounded mechanics regression, not a completed 51-year Madagascar
BAU/ICS run or proof for every regional input. Native compilation and external
report generation dominate different parts of production time; these tests
do not establish a new production speedup.

## Completed results, 2026-10-06

All five pairs passed. The three changing-cover cases preserved **1,035 of
1,035 comparable files byte for byte**, including all scientific rasters,
all CSV/scalar captures and all direct per-origin observers. Both fixed-cover
cases preserved all required scientific outcomes; their explicitly bounded
auxiliary differences occur only at initially excluded cells.

The total is **1,728 compared files**, with **1,608 byte-identical files** and
120 auxiliary raster differences governed by the existing initial-support
policy. There is no numerical tolerance. Saved-file comparisons were refreshed
using explicit `is.na` NoData comparisons; infinity cannot silently pass as
NoData.

Each candidate logged **32 warm NPA-cache loads**: four origin components over
the eight MC/year combinations following the initial cache creation. The
active-Patcher pair logged 36 actual Patcher executions; the other cases logged
18 transition-related Patcher executions. Thus the integration tests execute
both cache reuse and the stochastic allocation branch.

The companion reader gate passed for all five completed candidates: **360
full-grid vectors** matched the engine exactly (180 origin-pressure vectors,
90 TOF redistribution vectors and 90 aggregate vectors, each with 73,437
cells). Forty additional native-fragment eligibility/pressure replay vectors
and the legacy, missing-marker, partial-contract and mixed-contract guards
also passed. These checks bind to the same uninstrumented candidate hash.

All original zero/NoData, transition, class-return and missing-growth-parameter
cohort assertions passed for all three draws. In the persistent TOF-to-forest
cohorts, conversion-year stock and harvest were zero. In year 3, capped biomass
was zero and uncapped biomass was approximately 0.23785691 in model stock
units, so their vehicle masks and pressure remained zero. Positive eligibility
is established by the separate native fragment probes, as described above;
this short full-graph run does not demonstrate positive harvesting at these
particular cohorts.

The first dynamic-capped candidate attempt encountered the already observed
Windows 2.4 native-compiler DLL file lock before producing any scientific
output. It remains preserved as
`candidate__dynamic_capped__failed_native_attempt1`. A freshly staged native
retry succeeded. All completed gates use native expressions; no interpreter
fallback or model-arithmetic change was used to resolve the compiler failure.
