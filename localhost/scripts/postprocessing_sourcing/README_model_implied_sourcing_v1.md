# Model-implied sourcing approximation v1

`1post_model_implied_sourcing_v1.R` estimates origin-country to harvest-country
sourcing shares from already completed directional regional MoFuSS runs. It does
not modify the runs and does not claim to recover observed trade.

## Interpretation

- W uses each origin country's installed IDW component.
- V supports individual country components and pooled components. The script
  divides pooled components among their countries using national V demand
  shares, rescaled to the exact pooled demand supplied to MoFuSS.
- Realized harvest is divided among model pressure components proportionally.
- Harvest generated by other model processes is retained as a residual and is
  not assigned to household W or V demand.
- Country source totals use an aligned country-ID raster and its crosswalk.
  The batch pipeline discovers the run's `admin_c.tif`; a validated emissions
  `country_harvest_zones.tif` can be supplied as an override.

The important limitation is that the period IDW weights cannot reproduce the
annual biomass and Patcher eligibility masks used during the completed run.
Consequently these outputs are a model-implied approximation suitable for
diagnostics and ballpark sourcing shares. Stage 2 uses the richer recorded
runtime captures when they and the required annual diagnostics are available.

## Outputs

The default periods are inclusive: 2020-2030, 2030-2040, 2040-2050, and
2020-2050. The boundary years 2030 and 2040 therefore appear in both adjacent
decadal summaries; adjacent decadal rows must not be added together.

The script writes:

- `sourcing_matrix_by_mc.csv`: origin-source matrix for every MC realization.
- `sourcing_matrix_mc_summary.csv`: MC mean, SD, and SE for each matrix cell.
- `origin_sourcing_summary_by_mc.csv`: expected demand, realized harvest, and
  domestic/imported totals and percentages by origin and channel.
- `origin_sourcing_summary_mc_summary.csv`: MC summary of the origin results.
- `sourcing_matrix_combined_*.csv` and `origin_sourcing_combined_*.csv`:
  W+V combined results in addition to the separate-channel tables.
- `kenya_sourcing_summary.csv`: legacy Kenya-only extract containing W, V,
  and combined W+V rows; empty when Kenya is absent.
- `sourcing_conservation_qa.csv`: explicit harvest-conservation checks.
- `sourcing_methodology.csv`: machine-readable method and provenance notes.

## Run

Normally configure `0post_runtime_sourcing_pipeline_v1.R` and Source it in
RStudio. Its marked user-input block selects enabled regional batches, working
drives, neutral analysis folders, periods and Monte Carlo runs for both analyses.
See [the batch instructions and required exports](README_runtime_sourcing_v1.md).
There are no machine-specific default paths in this analysis.

To run this analysis alone from R on either operating system:

```r
source("/path/to/mofuss/localhost/scripts/postprocessing_sourcing/1post_model_implied_sourcing_v1.R")
mis_main(c(
  "--scenario-dir=/path/to/completed_scenario",
  "--zones=/path/to/admin_c.tif",
  "--boundaries=/path/to/country_crosswalk.csv",
  "--output-dir=/path/to/analysis/model_implied_sourcing",
  "--periods=2020:2020",
  "--mc-runs=1",
  "--check"
))
```

Replace the example paths with local paths (`E:/...` is valid on Windows).
Remove `--check` to calculate outputs. Repeat `--scenario-dir` for multiple
runs. `--boundaries` accepts a crosswalk CSV or a boundary GPKG. The same
arguments work with `Rscript`; sourcing the file only defines `mis_main()`.
